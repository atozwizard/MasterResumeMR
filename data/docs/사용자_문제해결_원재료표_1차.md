# 사용자 문제해결 원재료표 1차

## 목적
사용자의 경력과 브랜드 경험을 `문제 -> 조치 -> 결과 -> 증빙` 구조로 정리해, 리줌 bullet과 자기소개서 문장으로 바로 전환할 수 있는 원재료표를 만든다.

## 1. 한솔교육

- 경력:
  - `(주)한솔교육`
  - `2011.05 - 2015.09`

- 문제:
  - 관리 수업 수 확대가 필요한 상황
  - 운영 규모를 키우지 못하면 성장과 성과 증명이 어려운 상태

- 중요성:
  - 교육 영업 조직에서는 관리 수업 수와 성장률이 성과를 직접 보여주는 핵심 지표

- 조치:
  - 운영 구조와 실행 밀도를 높여 수업 수를 체계적으로 확대

- 결과:
  - 관리 수업 수 `50개 -> 150개`
  - `300%` 성장
  - 예비팀장 승진

- 현재 증빙:
  - 사용자 포트폴리오 문서
  - 자기소개서 진술

- 부족한 증빙:
  - 당시 성과 자료
  - 인사/평가 관련 문서

## 2. 커피소녀오즈

- 경력:
  - `커피소녀오즈`
  - 개인 브랜드 운영

- 문제:
  - 고객 페르소나별 니즈에 맞춘 공급 전략이 필요했던 상황
  - 단순 판매가 아니라 지속 거래 구조가 필요한 상황

- 중요성:
  - 브랜드 운영에서는 단발성 판매보다 장기 B2B 계약과 고객 맞춤 전략이 더 큰 안정성을 만든다

- 조치:
  - 고객 페르소나별 맞춤 원두 공급 전략 수립
  - 브랜딩, 마케팅, 광고물 제작까지 직접 주도

- 결과:
  - 장기 B2B 납품 계약 성사
  - 브랜드 라이프사이클 전 과정 경험 확보

- 현재 증빙:
  - 사용자 포트폴리오 문서
  - 자기소개서 진술
  - 공개 사업장 흔적
  - 공개 리뷰 기준 샌드위치/시그니처 음료/브랜드 경험 단서
  - 리뷰 집계 기준 `폐점` 상태 단서
  - 이용자 후기 기준 `샌드위치 만족도`, `시나몬 플랫화이트`, `생딸기우유`, `레몬워터`, `건강하고 행복한 한끼` 인식 단서

- 부족한 증빙:
  - 계약 수
  - 납품처 수
  - 운영 기간 세부
  - 매출 또는 거래 규모

## 3. 쿤타치 자가제면 / 우동오즈

- 경력:
  - `쿤타치 자가제면`
  - `우동오즈`

- 문제:
  - 점심시간이 짧은 상권 특성상 조리 지연이 고객 불만과 회전율 저하로 이어지는 문제
  - 긴 조리 시간과 공정 병목이 운영 효율을 떨어뜨리는 문제

- 중요성:
  - 외식업에서는 조리 속도와 회전율이 곧 매출과 고객 경험에 직결됨

- 조치:
  - 자가제면 공정을 데이터화해 분석
  - 병목 구간을 조정
  - 상권 특성에 맞춰 메뉴와 타겟 마케팅 조정

- 결과:
  - 서빙 시간 `7분 이내` 단축
  - 회전율 개선 서사 확보
  - 신메뉴/타겟 조정 경험 확보

- 현재 증빙:
  - 자기소개서 진술
  - 포트폴리오 진술
  - `쿤타치 자가제면` 공개 상호/주소/전화/위치 단서
  - `구 리틀방콕 자리` 단서
  - `우동오즈` 상호 흔적
  - `우동오즈` 주소 단서
  - `우동오즈` 피크 시간대/점심 집중형 운영 단서
  - `쿤타치 자가제면` 이용자 후기/블로그 스니펫 기준 `모던한 인테리어`, `넓은 공간`, `테이블 결제`, `사누끼우동 시그니처` 인식 단서
  - `우동오즈`는 유의미한 직접 후기보다 운영시간과 피크시간 같은 운영 단서 위주로만 확보

- 부족한 증빙:
  - 실제 매출 전후 데이터
  - 회전율 변화 수치
  - 조리시간 측정 기록
  - 운영 기간 세부
  - 사용자 직접 연관성 서류

## 4. 리틀방콕

- 경력:
  - `리틀방콕`
  - 프랜차이즈 운영 경험

- 문제:
  - 매장 운영의 표준화와 교육 체계가 필요한 상황

- 중요성:
  - HR, CS, 유통 구조가 정리되지 않으면 운영 품질과 확장성이 약해진다

- 조치:
  - HR 관리
  - CS 교육 매뉴얼 확립
  - 본사 유통 구조 경험 축적

- 결과:
  - 운영 체계화 경험 확보
  - 이후 브랜드 운영과 구조화된 문제 해결의 기반 형성

- 현재 증빙:
  - 포트폴리오 진술
  - `구 리틀방콕 자리` 단서
  - `리틀방콕 중계점` 공개 장소 단서
  - 서울 노원구 동일로207길 23 주소 단서
  - `주중 11:00 ~ 21:30` 영업시간 단서
  - 태국음식 전문점 소개 단서
  - 공개 기업정보 페이지의 대표자명/주소 단서
  - 이용자 후기 기준 `직원 친절`, `밝고 깨끗한 분위기`, `양 많음`, `재방문 의사`, `메뉴별 호불호` 단서

- 부족한 증빙:
  - 실제 직함
  - 운영 기간
  - 매뉴얼, 교육자료, 운영지표
  - 사용자 역할 범위와 중계그린점 연관 직접 증빙
  - 운영 성과 수치

## 5. AI 전환 이후 학습 아카이브

- 경력:
  - sesac AI Agent 과정
  - 학습 아카이브, 스터디, 해커톤, 코딩테스트

- 문제:
  - 전공 지식과 실무 역량의 간극
  - 비즈니스 경험을 AI 엔지니어링 역량으로 전환해야 하는 문제

- 중요성:
  - AI 전환 서사에서 중요한 것은 단순 학습이 아니라 실제 문제 해결형 역량으로 전환되었는가 여부

- 조치:
  - 매일 기술 스냅샷 복기
  - 공식 문서 학습
  - 에러 로그 분석
  - 학습 아카이브 기록
  - 스터디와 프로젝트 병행

- 결과:
  - AI Agent, RAG, 멀티에이전트, 운영형 구조 프로젝트 수행
  - 공개 저장소와 산출물 축적

- 현재 증빙:
  - GitHub 공개 프로필
  - GitHub 공개 저장소 메타데이터
  - 자기소개서 진술
  - 포트폴리오 문서

- 부족한 증빙:
  - 수료/재학 증빙
  - 해커톤 결과
  - 발표 자료

## 강한 수치 근거 탐색 결과
- 공개 검색 기준으로 `매출`, `회전율`, `조리시간 기록`의 직접 출처는 아직 확보하지 못함
- 대신 아래 보조 지표는 확보함
  - `커피소녀오즈`: 인허가일자, 시설 규모, 메뉴/리뷰 키워드, 폐점 상태
  - `우동오즈`: 점심/저녁 피크 시간 단서, 점심 집중형 운영시간 단서
  - `쿤타치 자가제면`: 신상 매장, 위치, 공간 전환 단서
  - `리틀방콕 중계점`: 주소, 영업시간, 업종, 공개 기업정보 단서
- 정성 데이터 관점에서 추가 확보한 것
  - `커피소녀오즈`: 메뉴 만족도, 시그니처 음료 인식, 식사형 카페 경험, 작은 서비스 디테일 단서
  - `쿤타치 자가제면`: 공간감, 주문/결제 방식, 시그니처 메뉴 인식 단서
  - `우동오즈`: 후기형 정성 데이터는 약하고 운영 단서 위주
  - `리틀방콕 중계점`: 친절도, 청결감, 양에 대한 인식, 재방문 의사, 메뉴별 편차 단서
- 따라서 현재 단계에서는 `강한 숫자 근거 없음`, `맥락형 보조 근거 있음`으로 구분해 써야 함

## 다음 작업

2. 각 항목에 대응하는 리줌 bullet 후보를 2개씩 만든다.
3. 사용자 직접 증빙이 들어오면 `현재 증빙` 칸을 교체한다.
