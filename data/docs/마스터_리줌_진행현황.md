# 마스터 리줌 진행현황

## 목적
저장소, 자기소개서, 프로젝트 문서에서 검증 가능한 근거를 수집해 마스터 리줌과 직무별 리줌으로 재구성한다.

## 현재 상태
- 자료 수집 템플릿 작성 완료
- GitHub 저장소 수집 완료
- README 감사 및 일부 보강 완료
- 저장소 원노트 1차 작성 완료
- 기여 커밋 근거 정리 완료
- 직무별 bullet 초안 작성 완료
- `기술문제 해결`과 `비즈니스문제 해결` 두 관점, 그리고 각 관점의 `왜`까지 반영하도록 기준 재정의 완료

## 핵심 원칙
- 모든 프로젝트는 `무엇을 했는가`, `왜 했는가`, `어떻게 했는가`, `결과가 어땠는가`를 남긴다.
- 모든 bullet은 두 관점을 함께 갖는다.
  - `기술문제 해결`: 왜 그 구조와 기술을 선택했는가
  - `비즈니스문제 해결`: 왜 그 문제가 사용자·조직·업무에 중요한가
- README가 부실하면 코드 구조, 설정 파일, 커밋, 산출물 기준으로 재구성한다.
- 수치가 없으면 과장하지 않고 운영성, 안정성, 추적성, 설명 가능성으로 표현한다.

## 지금까지 해결한 것
- 저장소 원노트를 프로젝트별로 정리해 리줌의 원재료를 확보했다.
- 커밋 기준으로 본인 기여 가능성이 높은 파일을 좁혔다.
- 직무별 bullet 초안을 `AI Engineer`, `Backend Engineer`, `Product Engineer` 관점으로 분리했다.
- 기존의 `무엇을 했다` 중심 문장을 `왜 그렇게 풀었는지`, `왜 중요한지`가 드러나는 문장으로 보강했다.

## 남은 과제
1. 각 프로젝트별 결과 수치와 산출물 링크 보강
2. 프로젝트별 `왜` 문장 구체화
3. 직무별 최종 bullet 5~7개 선별
4. 한 페이지용 마스터 리줌 초안 생성

## 다음 우선순위

3. 실제 제출용 리줌 문장으로 압축
