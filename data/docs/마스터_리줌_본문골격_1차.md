- 제품 정체성을 유지하면서 운영 효율을 높이는 문제를 다뤘다.

- 학습 내용을 기록과 프로젝트로 연결하는 자기주도형 구조를 유지하고 있다.

## 대표 프로젝트

### company_analyzer
- 분산된 JD, 기술 블로그, 제품 문서, GitHub 저장소를 하나의 분석 흐름으로 묶으면서도 결과 출처를 추적할 수 있도록 LangGraph 기반 멀티에이전트 파이프라인을 설계했다.
- 기업 요구 역량과 사용자 보유 역량을 분리 분석한 뒤 연결하는 흐름을 설계해, 적합성을 설명 가능한 형태로 구조화했다.

### job-analyzer
- Python AST 정적 분석과 임베딩 기반 유사도 계산을 결합해, 코드 구조와 역할까지 해석하는 저장소 분석 구조를 구현했다.
- JD 분석, 저장소 분석, 외부 정보 수집을 묶어 기술 경험을 업무 가치 언어로 번역하는 흐름을 만들었다.

### trade-onboarding-agent
- stale state와 비동기 처리 누락 문제를 수정해, 상태 일관성과 처리 안정성을 우선하는 구조로 정비했다.
- 리스크 분석, 이메일 초안, 퀴즈 생성 기능을 업무 단위로 분리해 실제 교육 흐름에 가까운 구조를 만들었다.

### idol_agent_LUMI
- LiteLLM fallback, checkpoint, 비용 추적, Langfuse 연동을 포함한 운영형 구조를 구현했다.
- 생성 품질뿐 아니라 장애 대응과 추적 가능성을 함께 고려한 서비스형 AI 구조를 정리했다.

### manufacturing-ai-coach
- 센서 데이터, 유지보수 이력, SOP 문서를 함께 참조하는 RAG 기반 복합 데이터 진단 구조를 설계했다.
- 진단, 문서 검색, 추천 조치, 확인 흐름을 연결해 유지보수 의사결정 보조 도구로 설명 가능한 구조를 만들었다.
