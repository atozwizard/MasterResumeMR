# Backend_Engineer_본문초안_1차

## 핵심 메시지
운영 병목과 상태 문제를 구조로 풀어내며, 안정적으로 동작하는 서비스 흐름을 설계하는 Backend Engineer 지향 인재.

## 프로필
비즈니스 운영 현장에서 병목, 표준화, 흐름 문제를 직접 경험했고, 이를 AI 서비스와 백엔드 구조 설계 경험으로 연결해 왔다.

## 경력 요약
- 운영 병목을 데이터와 프로세스 기준으로 해석하는 데 강점이 있다.
- 점심 집중형 상권에서 조리 병목을 줄이는 운영 최적화를 시도했고, 회전율 중심 운영 문제를 공정과 흐름 관점에서 다뤘다.
- 자가제면 공정과 매장 동선을 함께 고려해 피크타임 운영 병목을 줄이는 방향으로 운영 구조를 정비했다.
- 프랜차이즈 매장에서 HR, CS, 본사 유통 구조를 경험하며 운영 표준화의 중요성을 체득했다.
- 한솔교육에서 운영 구조와 실행 방식을 정비해 관리 수업 수를 안정적으로 확대했다.

## 대표 프로젝트

### trade-onboarding-agent
- stale state와 비동기 처리 누락 문제를 수정해, 상태 일관성과 처리 안정성을 우선하는 구조로 정비했다.
- 리스크 분석, 이메일 초안, 퀴즈 생성 기능을 업무 단위로 분리해 실제 교육 흐름에 가까운 구조를 만들었다.

### idol_agent_LUMI
- LiteLLM fallback, checkpoint, 비용 추적, Langfuse 연동을 포함한 운영형 구조를 구현했다.
- 생성 품질뿐 아니라 장애 대응과 추적 가능성을 함께 고려한 서비스형 AI 구조를 정리했다.

### company_analyzer
- LangGraph 기반 멀티에이전트 파이프라인을 설계해 수집과 해석 단계를 분리하고, 결과 출처를 추적 가능한 구조로 만들었다.
- 기업 요구 역량과 사용자 보유 역량을 연결하는 흐름을 구조화해 설명 가능한 서비스 흐름으로 정리했다.

## 기술 스택
- Python, SQL
- FastAPI, Docker
- RAG, MCP
- Cloud 환경

## 강점
- 상태 일관성과 운영 안정성을 우선 고려함
- 병목 완화와 흐름 설계 경험이 있음
- 오프라인 운영 문제를 시스템 구조로 바꿔 설명할 수 있음
