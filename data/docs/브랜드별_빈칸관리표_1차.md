# 브랜드별_빈칸관리표_1차

## 목적
브랜드별 경력에서 아직 비어 있는 핵심 항목을 한 곳에 모아, 이후 사용자 직접 증빙이나 추가 공개 자료가 들어왔을 때 즉시 보강할 수 있도록 관리한다.

## 상태 기준
- `확정`: 현재 문서와 근거로 바로 써도 되는 항목
- `추정`: 방향성은 있으나 직접 증빙이 부족한 항목
- `미확인`: 아직 사실로 쓰면 안 되는 항목

## 사용 원칙
- `확정` 항목은 바로 마스터 리줌 원재료에 넣는다.
- `추정` 항목은 면접 설명용 또는 보조 문장으로 유지한다.
- `미확인` 항목은 직접 증빙이 들어오기 전까지 본문에서 단정하지 않는다.
