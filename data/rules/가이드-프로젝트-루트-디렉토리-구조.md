# 프로젝트 루트 디렉토리 구조 가이드

## 목적

현재 저장소의 문서, 원본 자료, 로그, 외부 저장소를 역할별로 분리해 관리하기 위한 기준입니다.

## 루트 기준 구조

```text
MasterResumeMR/
├─ data/
│  ├─ docs/
│  │  ├─ plans/
│  │  └─ templete/
│  ├─ logs/
│  ├─ rules/
│  └─ user/
├─ repo/
├─ .gitignore
└─ .pre-commit-config.yaml
```

## 디렉터리 역할

### `data/docs/`
- 마스터 리줌 재료 문서
- 저장소 원노트
- bullet 초안
- 진행 정리 문서

### `data/docs/plans/`
- 단계별 실행 계획
- A트랙/B트랙 선별 문서
- phase 계획 문서

### `data/docs/templete/`
- 자료수집 템플릿 등 재사용 문서

### `data/logs/`
- 날짜별 대화로그
- 날짜별 진행현황
- 기록 규칙

### `data/rules/`
- 운영 기준 문서
- README/마일스톤/브랜치/절차 가이드

### `data/user/`
- 사용자 원본 자료
- 이력서, 포트폴리오, 자기소개서, 보조 메모

### `repo/`
- 프로젝트 근거 확보용 저장소 클론
- 마스터 리줌용 raw data 소스

## 운영 원칙

- 계획 문서는 `data/docs/plans/`에 저장합니다.
- 사용자 원본은 `data/user/`에서 직접 수정하지 않고, 추출 결과를 `data/docs/`로 분리합니다.
- 로그는 날짜 기준 파일로 관리합니다.
- 외부 저장소 코드는 `repo/`에 유지하고 루트 Git과는 분리해 다룹니다.

## 체크리스트

- [ ] 새 문서가 맞는 디렉터리에 저장되었는가
- [ ] 원본 자료와 가공 문서가 분리되어 있는가
- [ ] 경로 설명이 현재 저장소 구조와 일치하는가
