# AGENTS.md 업데이트 규칙

## 목적

- `AGENTS.md`를 현재 프로젝트의 단일 진입점으로 유지합니다.
- 상세 규칙은 `data/rules/*.md`에 두고, `AGENTS.md`는 요약과 참조 경로 중심으로 관리합니다.

## 적용 범위

- `data/rules/AGENTS.md` 수정
- `data/rules/README.md` 인덱스 갱신
- 관련 규칙 문서 경로 변경 시 참조 경로 정리

## 운영 원칙

- `AGENTS.md`에는 핵심 원칙과 진입 경로만 남깁니다.
- 세부 규칙은 개별 가이드 문서로 분리합니다.
- 변경 전에는 `data/rules/README.md`와의 연결 상태를 확인합니다.

## 기본 절차

1. 작업 유형을 분류하고 `data/rules/README.md`에서 기준 문서를 확인합니다.
2. 변경이 필요한 규칙 문서를 먼저 수정합니다.
3. `AGENTS.md`는 요약 수준으로 최소 수정합니다.
4. 인덱스 문서에 신규/변경 항목을 반영합니다.

## 체크리스트

- [ ] `AGENTS.md`가 현재 프로젝트 문맥과 맞는가
- [ ] `data/rules/README.md` 인덱스가 최신인가
- [ ] 참조 경로가 현재 저장소 구조와 일치하는가
