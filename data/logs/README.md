# Logging Convention

This directory stores session-based records for the master resume workflow.

## File Types
- `conversation_YYYY-MM-DD_HHMMSS.md`
- `progress_YYYY-MM-DD_HHMMSS.md`

## Rule
- Create a new pair of files when the calendar date changes.
- On the same date, keep appending updates to the active day's files if continuing the same working stream.
- Record:
  - what the user requested
  - what plan was set
  - what was attempted
  - what was completed
  - what remains next
