# poketdogam

## 한 줄 설명
`chat`, `scan`, `pokedex` 흐름을 나눠 멀티모달 사용자 경험을 설계한 프로젝트입니다.

## 핵심 내용
- 질문 처리, 이미지 스캔, 도감 조회 역할을 분리했습니다.
- 스캔 흐름에는 `입력 수집 -> OCR/후보 확인 -> 문맥 검색 -> 응답 생성 -> trace 저장` 단계를 뒀습니다.
- OCR 결과가 바로 확정되지 않는 상황을 가정해 후보 확인과 fallback 방향을 함께 설계했습니다.

## 왜 중요한가
이 프로젝트의 핵심은 기술 자체보다 사용자 경험 설계입니다. 멀티모달 입력이 실패할 때도 다음 경로를 설명할 수 있어야 실제 서비스로 이어질 수 있기 때문입니다.
