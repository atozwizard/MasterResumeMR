# 기업 분석 고도화 프로젝트 `company_analyzer_v2`

`company_analyzer_v2`는 GitHub 활동과 프로젝트 흔적을 포트폴리오 서사로 바꾸는 데 초점을 둔 확장 버전입니다. 단순 자동 작성이 아니라, 코드와 커밋, 제품 설명문, 요구 역량 추론을 `근거 기반`으로 연결하는 구조를 목표로 합니다.

핵심 난점은 사용자의 경험을 설명 가능한 서사로 바꾸는 과정에서 근거 추적성과 재현성을 함께 확보해야 한다는 점이었습니다. 이를 위해 HybridRAG, milestone 운영 정비, 에이전트 I/O 계약 안정성 검증을 우선하는 방향으로 발전했습니다.

이 프로젝트는 서비스 관점에서는 포트폴리오 생성형 분석 시스템이고, 연구 관점에서는 `설명 가능한 요구 역량 추론`, `sparse data 보강`, `근거 역추적` 구조를 실험하는 프로젝트입니다.
