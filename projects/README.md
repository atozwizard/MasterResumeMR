# Projects

이 디렉토리는 공개용 대표 프로젝트만 정리한 공간입니다. 구현, 연구, 기획을 분리해 읽을 수 있도록 구성했습니다.

## Representative Implementation Projects
- [company_analyzer](./company_analyzer.md): 기업 요구와 사용자 경험을 같은 분석 언어로 연결하는 멀티에이전트 구조
- [company_analyzer_v2](./company_analyzer_v2.md): HybridRAG와 포트폴리오 생성 흐름까지 확장한 분석 고도화 버전
- [job-analyzer](./job-analyzer.md): AST 기반 구조 분석과 의미 분석을 결합한 저장소 해석 프로젝트
- [trade-onboarding-agent](./trade-onboarding-agent.md): 상태 흐름 안정성과 비동기 처리 정합성을 다룬 온보딩 에이전트
- [idol_agent_LUMI](./idol_agent_LUMI.md): fallback, checkpoint, tracing을 포함한 운영형 AI 서비스 구조
- [poketdogam](./poketdogam.md): 사용자 경험과 서비스 전달 구조를 전면에 둔 제품형 프로젝트
