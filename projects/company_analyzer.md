# company_analyzer

기업 요구 역량과 사용자 경험을 같은 언어로 비교할 수 있도록, 채용 공고, 기술 블로그, 제품 문서, GitHub 저장소를 수집·분석·매핑하는 멀티에이전트 분석 프로젝트입니다.

이 프로젝트의 핵심 문제는 정보가 분산되어 있고, 단순 키워드 비교만으로는 적합도를 설명하기 어렵다는 점이었습니다. 이를 해결하기 위해 기업 분석 흐름과 사용자 분석 흐름을 병렬로 나누고, 마지막에 근거 기반 매핑으로 연결하는 구조를 택했습니다.

이 프로젝트는 단순 요약기가 아니라 `설명 가능한 적합도 분석 서비스`에 가깝습니다. 사용자는 자신의 경험을 기업 요구 역량과 연결된 형태로 다시 읽을 수 있고, 분석 결과는 포트폴리오 생성과 문서 작성까지 이어질 수 있습니다.
