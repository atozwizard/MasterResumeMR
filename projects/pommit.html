01. POMMIT

NLP 전처리의 시작점과 HybridRAG 확장 방향 검토

프리뷰

해커톤 기반 팀 POMMIT에서 company_analyzer의 기업 분석 축을 맡아, service_agent 최소기능과 운영 문서를 정리하고 NLP 전처리에서 HybridRAG 방향까지 이어지는 다음 단계를 검토한 협업 프로젝트입니다.

내 역할

  • service_agent 최소기능 방향 설계와 구현 정리
  • HTML 정리 -> 텍스트 정제 -> 단어 빈도 추출 -> collector 전달 흐름 구체화
  • 상태 스키마, 문서 구조, 마일스톤 운영 기준 정리
  • HybridRAG, NLP 전처리, sparse data 보강 방향 검토 및 문서화

왜 중요했는가

company_analyzer는 여러 에이전트가 동시에 개발되는 구조라서, 기능을 빨리 붙이는 것만으로는 앞으로 나가지 않았습니다. 각 에이전트가 무엇을 받고 무엇을 넘기는지, 어떤 산출물을 남기는지, 팀이 어떤 기준으로 작업을 관리할지가 먼저 잡혀야 했고, 서비스 설명문에서 요구역량을 어떻게 추출할지도 함께 정리돼야 했습니다.

NLP 전처리 관점

서비스 설명문에서 요구역량을 뽑아내려면 원문 HTML을 그대로 넘기는 것보다 먼저 문서 노이즈를 제거하고, 의미 있는 텍스트만 남기고, 최소 단위의 단어 신호를 정리해야 합니다. 저는 이 출발점을 service_agent 안에 두었습니다. 현재 구현은 형태소 분석 전체가 아니라 전처리와 근거 신호 정리의 시작점이며, 이 단계가 있어야 이후 형태소 분석기 도입이나 HybridRAG가 설명 가능한 구조로 붙습니다.

결과

service_agent와 collector_agent를 잇는 단어 빈도 최소기능이 반영됐고, 상태 스키마와 객체 전달 흐름이 정리되면서 이후 에이전트 연결을 더 설명 가능하게 다룰 수 있는 기반이 생겼습니다. 이 프로젝트는 복잡한 에이전트 프로젝트 안에서 구조를 먼저 세우고 NLP 처리 방향과 다음 실험 방향까지 정리하는 사람이라는 점을 보여줍니다.
