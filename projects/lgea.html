02. LGEA

persona 기반 모델 가드레일 붕괴 테스트

프리뷰

실행 중인 LUMI FastAPI와 내부 service surface를 실제로 두드려, 질문 실행 -> 채점 -> 비교 분석 -> 보고서 생성까지 분리한 모델 평가 워크스페이스입니다.

무엇을 테스트했는가

  • 실제 LUMI FastAPI /api/v1/chat/
  • 내부 service surface: router, response-layer, rag, tool
  • baseline_questions.json 기반 공통 질문 세트
  • abuse category, benign probe, persona source

어떻게 구성했는가

runner -> judge -> analysis -> reports 구조로 질문 실행, 채점, 분석, 보고서를 분리했습니다. 같은 질문 세트를 FastAPI와 service surface에 보내고, 실행 결과를 JSONL로 남긴 뒤, 표면·카테고리·모델 단위로 통계를 만들고 보고서까지 생성합니다.

왜 중요한가

LGEA는 일반적인 서비스 테스트가 아니라, persona에 따라 모델 guardrail이 어떤 표면에서 더 쉽게 무너지는지 반복 가능하게 확인하는 평가 체계입니다. 결과는 JSONL, scored result, 통계 요약, 보고서 형태로 남아 이후 비교와 설명의 근거가 됩니다.
