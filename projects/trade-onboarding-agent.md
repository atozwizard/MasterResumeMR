# trade-onboarding-agent

무역 실무 입문자를 위한 온보딩형 AI 에이전트 프로젝트입니다. 핵심 난점은 상태 흐름과 비동기 처리 안정성을 유지하면서, 교육형 업무 흐름을 자연스럽게 묶는 것이었습니다.

이 프로젝트에서는 stale state와 비동기 처리 누락 문제를 다루며, 상태 일관성과 처리 안정성을 우선하는 구조로 정비했습니다. 또한 리스크 분석, 이메일 초안, 퀴즈 생성 기능을 업무 단위로 나누어 교육형 서비스에 가까운 흐름을 만들었습니다.

`Backend Engineer`와 `AI Engineer` 직무 모두에서 강하게 활용할 수 있는 프로젝트입니다.
