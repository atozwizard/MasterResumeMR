# job-analyzer

`job-analyzer`는 채용 공고와 GitHub 저장소를 함께 분석해, 코드 경험을 기술 스택 나열이 아니라 역할과 비즈니스 가치 언어로 번역하는 프로젝트입니다.

일반적인 저장소 분석은 사용 기술 목록만 뽑아내고 끝나는 경우가 많습니다. 이 프로젝트는 이를 넘어서기 위해 AST 기반 구조 분석과 임베딩 기반 의미 분석을 결합했습니다. 먼저 구조를 읽고, 그다음 중요한 코드만 좁혀 읽는 방식으로 비용과 설명 가능성을 함께 관리했습니다.

결과적으로 이 프로젝트는 지원자에게는 포지셔닝 분석 도구, 기업에게는 설명형 적합도 평가 도구로 해석할 수 있습니다.
