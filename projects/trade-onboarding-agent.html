03. trade-onboarding-agent

RAG와 riskmanaging agent를 중심으로 다룬 무역 온보딩 미니프로젝트

프리뷰

무역 실무 온보딩 미니프로젝트에서 RAG와 riskmanaging agent 흐름을 중심으로 작업했습니다.

무엇을 했는가

  • 무역 도메인 데이터 ingest와 ChromaDB 기반 검색 구조를 중심으로 RAG 흐름을 정리했습니다.
  • riskmanaging agent 문서와 백엔드 흐름을 기준으로 리스크 질문에 근거 기반 답변이 이어지는 구조를 다뤘습니다.
  • 프로젝트 전체 오케스트레이션을 과장하기보다, 직접 확인하고 정리한 RAG와 riskmanaging 중심 작업 범위로 설명합니다.
