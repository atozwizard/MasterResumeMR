이영기

현장의 문제를 흐름과 구조로 풀어, 운영 가능한 AI로 만드는 엔지니어입니다.

창업과 외식업 운영, 프랜차이즈 현장에서 고객 경험, 병목, 서비스 품질, 인력 운영 문제를 직접 다뤘습니다. AI 전환 이후에도 문제를 보는 방식은 같습니다. 입력이 어떤 상태를 만들고, 그 상태가 어떤 판단과 분기로 이어지며, 마지막에 무엇을 남겨야 다시 비교하고 운영할 수 있는지를 먼저 봅니다.

핵심 역량

  • 상태, 분기, fallback, tracing을 포함한, 운영 가능한 AI 구조 설계
  • 사용자 문제와 운영 병목을 제품 흐름으로 번역
  • 실험, 채점, 분석을 분리한 평가 구조 설계
  • 문서와 리포트까지 포함한 산출물 정리

대표 프로젝트

  • 1. POMMIT

    기업 분석 프로젝트 안에서 service_agent 흐름을 중심으로 HTML 정리, 텍스트 정제, 단어 빈도 추출, collector 전달 구조를 정리했습니다. 이후에는 NLP 전처리 강화와 HybridRAG 방향을 연구 메모와 설계 문서 수준에서 검토했습니다.

  • 2. LGEA

    LUMI 서비스 응답을 실제로 테스트하는 평가 워크스페이스입니다. runner -> judge -> analysis -> reports 구조로 질문 실행, 채점, 비교 분석, 보고서 생성을 분리했고, persona에 따른 모델 가드레일 붕괴를 비교하는 실험 흐름을 다뤘습니다.

  • 3. trade-onboarding-agent

    무역 실무 온보딩 미니프로젝트에서 RAG와 riskmanaging agent 흐름을 중심으로 작업했습니다. 무역 도메인 데이터 ingest, ChromaDB 기반 검색 구조, riskmanaging agent 문서와 백엔드 흐름을 정리하고, 리스크 질문을 RAG 근거와 함께 응답하는 구조를 다뤘습니다.

  • 4. poketdogam

    chat, scan, pokedex 흐름을 나눠 멀티모달 사용자 경험을 설계했습니다. 스캔 흐름에는 입력 수집 -> OCR/후보 확인 -> 문맥 검색 -> 응답 생성 -> trace 저장 단계를 두고 fallback을 함께 설계했습니다.

  • 5. LUMI

    청년취업사관학교 교육과정 안에서 구조, 아키텍처, 배포, LLMOps까지 학습하기 위해 진행한 운영형 AI 서비스 본체입니다. 상태, 저장, token/cost tracking, tracing, RAG, fallback 구조를 갖췄고, LGEA는 이 서비스를 검증하는 별도 평가 레이어입니다.
