# master

`master/`는 마스터 리줌 원재료를 항목별로 분해하고, A트랙 프로젝트 보고서와 B트랙 사용자 경험 자료를 한 디렉토리에서 재사용할 수 있도록 정리한 작업 공간이다.

## 구성
- 범용 마스터 리줌 분해본
- 대표 프로젝트 선별표
- 레포지토리별 프로젝트 보고서 복사본
- 보고서가 없는 핵심 저장소의 루트 `README.md` 복사본
- 사용자 경험 추출본
- 사용자 활동 추출본

## 사용 원칙
- 여기의 문서는 `압축본`이 아니라 `방어력 있는 원재료집`으로 사용한다.
- 기업 맞춤형 리줌은 여기서 항목을 선별해 조합한다.
- 정량 증빙이 없는 항목은 과장하지 않고, 정성 근거와 직접 증빙 필요 여부를 분리해 다룬다.
