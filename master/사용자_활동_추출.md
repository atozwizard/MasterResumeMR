# 사용자_활동_추출

## 목적
`data/user` 자료에서 경력 외 활동, 스터디, 발표, 학습 아카이브, 공모전/동아리 경험을 분리 추출한다.

## 주요 활동

### SESAC x UPSTAGE AI Agent 과정
- 기간: `2025.12 - 2026.05 예정`
- 성격: AI Agent 서비스 기획부터 배포까지 다루는 집중 교육 과정
- 확인 내용:
  - Python, SQL, RAG, 프로젝트 기반 학습
  - 실습 결과를 GitHub 프로젝트로 연결

### 마이크로소프트 해커톤 기반 프로젝트 동아리 `POMMIT`
- 성격: 일정 기반 실전 프로젝트 협업
- 확인 내용:
  - 공모전 수준 결과물 지향
  - 팀 기반 프로젝트 운영 경험
  - 클론한 레포지토리 기준 현재 `company_analyzer` 프로젝트를 진행 중
  - 사용자 GitHub 활동과 연결되는 실전 AI 에이전트 프로젝트 협업 축으로 해석 가능

### 코딩테스트 스터디
- 저장소: `programmers-high-score-kit`
- 빈도: 주 2회 서술 존재
- 확인 내용:
  - 알고리즘 기본기 강화
  - 문제 해결 및 코드 리뷰 활동

### 주말 기술 트렌드 스터디
- 성격: AI 트렌드, LLM 구조, 논문/기술 아티클 공유
- 확인 내용:
  - 최신 기술 흐름 학습
  - 개념을 설명 가능 언어로 정리하는 활동

### 발표 활동
- 확인된 발표 주제:
  - `Tokenizer`
  - `Transformer 구조`
  - `LLM 경량화 기법`
  - `Lost in the middle`
- 활용 포인트:
  - 학습 내용을 발표 자료로 구조화
  - 기술 개념을 타인에게 설명하는 역량

### 학습 아카이브 개인 프로젝트
- 성격: 배운 기술적 난제와 해결 과정을 기록하는 자기주도형 아카이브
- 활용 포인트:
  - 휘발되는 학습 내용을 자산화
  - 오류와 해결 과정을 구조적으로 축적

## 보조 활동 및 이수
- 유튜브 콘텐츠 크리에이터 과정
- 영상 모션 편집
- 웹개발 종합반
- 웹 크롤링 관련 학습

## 자기소개서 기반 활동 해석
- 가장 먼저 출근하고 가장 늦게 퇴근하는 학습 태도
- 새벽 통근과 장시간 몰입 학습 경험
- 실패와 폐업 경험을 기술 전환 동력으로 재해석

## 활용 원칙
- 활동 항목은 `열정`만 강조하지 않고 `지속성`, `구조화`, `산출물 연결` 중심으로 쓴다.
- 발표와 스터디는 단순 참가보다 `무엇을 정리했고 어떤 산출물을 남겼는가` 기준으로 연결한다.
- 공모전/동아리 경험은 협업 구조, 일정 관리, 결과물 생산 관점에서 설명한다.
