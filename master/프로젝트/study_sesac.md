# 프로젝트 문제해결 서비스보고서

## 프로젝트명
`study_sesac`

## 한 줄 요약
Python 기초, 알고리즘, 프롬프트 설계, LLM 주말 스터디, 코딩 테스트 연습을 누적한 개인 학습 아카이브 저장소.

## 1. problem solve 관점

### 어떤 문제를 풀려 했는가
- AI 전환 초기에는 기초 체력과 문제 해결 훈련이 분산되기 쉽고, 한 저장소 안에서 학습 흔적을 연결해 관리하기 어렵다.
- 알고리즘, Python, 프롬프트, LLM 이론을 따로 공부하면 누적 경로가 보이지 않는다.
- 이후 리줌이나 포트폴리오에서 학습의 폭과 깊이를 설명할 근거가 필요했다.

### 왜 이 방식으로 풀었는가
- 코딩 테스트 풀이, Python 연습, 주말 연구 노트를 한 저장소에 두면 학습 범위와 진행 방향을 함께 보여줄 수 있다.
- 실습 노트북과 메모, PDF, 텍스트를 그대로 남겨두면 학습 과정의 실제 흔적이 된다.
- 완성형 서비스가 아니라도 `학습 누적 증거`를 저장소 수준에서 관리할 수 있다.

### 어떻게 구현했는가
- LeetCode, Wikidocs Python 300, 주말 스터디, 알고리즘 강의 자산을 주제별 폴더로 분리했다.
- 프롬프트 템플릿, Git 메모, Python 실습 노트북을 함께 보관했다.
- 저장소 루트 README를 통해 전체 학습 범위와 사용 목적을 설명했다.

## 2. project service 관점

### 서비스라기보다 무엇인가
- 이 저장소는 사용자 대상 서비스가 아니라 `개인 학습 증빙 아카이브`다.
- 배포형 제품보다는 학습 범위, 지속성, 관심 주제를 보여주는 내부 포트폴리오 자료에 가깝다.

### 사용자 가치
- 학습자 본인에게는 복습과 정리 자산이 된다.
- 외부 평가자에게는 Python 기초, 알고리즘, LLM 관련 자율 학습 흔적으로 읽힌다.

### 리줌 관점 의미
- 기초 체력 형성
- 주제별 자율 학습
- 문제 풀이와 실습 누적

## 3. 리줌에 쓸 수 있는 포인트
- Python, 알고리즘, 프롬프트 설계, LLM 주제 연구를 아우르는 개인 학습 아카이브 구축
- 문제 풀이와 개념 학습을 주제별로 누적 관리
- AI 전환 초기에 필요한 기초 역량을 지속적으로 축적한 흔적
