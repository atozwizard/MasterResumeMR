# 프로젝트 문제해결 서비스보고서

## 프로젝트명
`retry`

## 한 줄 요약
OpenAI API 사용, MMLU형 평가, temperature 비교, zero-shot/few-shot 실험을 단일 노트북 안에서 반복해 본 프롬프트 실습 저장소.

## 1. problem solve 관점

### 어떤 문제를 풀려 했는가
- LLM 응답은 프롬프트 방식과 temperature 설정에 따라 달라지므로, 기본적인 비교 실험이 필요하다.
- 단순 호출만으로는 모델 응답 특성과 평가 흐름을 이해하기 어렵다.

### 왜 이 방식으로 풀었는가
- 노트북 안에서 API 호출, 선택지 평가, zero-shot/few-shot 비교를 한 번에 해보면 설정 변화가 결과에 어떤 영향을 주는지 빠르게 확인할 수 있다.
- 단일 저장소/단일 노트북 구조는 초기 실습 기록을 남기기에 적합하다.

### 어떻게 구현했는가
- OpenAI Python SDK 설치와 기본 호출
- MMLU 스타일 객관식 평가 실습
- temperature 비교
- zero-shot vs few-shot 비교
- `Counter`를 이용한 간단한 응답 분포 분석

## 2. project service 관점

### 서비스라기보다 무엇인가
- 이 저장소는 배포형 서비스가 아니라 `프롬프트 및 모델 응답 실험 노트북`이다.
- 리줌 관점에서는 제품보다 `실험 기반 학습 흔적`으로 읽는 것이 맞다.

### 리줌 관점 의미
- 프롬프트 방식 차이 실험
- 모델 응답 비교와 평가 감각
- API 사용 기초 학습
