# 프로젝트 문제해결 서비스보고서

## 프로젝트명
`sesac_upstage_ai_study`

## 한 줄 요약
5주차 SESAC Upstage AI 과정을 주차/일차/예제 3계층 구조로 정리해, 단순 메모가 아니라 `학습 시스템`처럼 관리한 아카이브 저장소.

## 1. problem solve 관점

### 어떤 문제를 풀려 했는가
- 학습량이 많아질수록 강의 내용, 실습 예제, 핵심 개념이 흩어져 복습과 재사용이 어려워진다.
- 단순 노트 모음 방식은 시간이 지나면 어떤 주차에서 무엇을 배웠는지 찾기 어렵다.
- 배운 내용을 다시 코드와 설명으로 꺼내 쓸 수 있도록 구조화된 학습 아카이브가 필요했다.

### 왜 이 방식으로 풀었는가
- 주차 개요, 일일 상세, 코드 예제를 3계층으로 나누면 개념 복습과 실습 재사용이 쉬워진다.
- HTML 대시보드를 붙이면 코드만 모아둔 저장소보다 탐색성과 회고 효율이 높아진다.
- 학습 기록을 구조화해 두면 이후 리줌, 포트폴리오, 면접 답변의 근거로 다시 활용하기 좋다.

### 어떻게 구현했는가
- 5주차 과정을 주차별 모듈, 일별 학습 모듈, 예제 코드로 나눴다.
- `index.html`을 통해 주차/일차/개념 단위로 탐색 가능한 대시보드를 구성했다.
- Python 모듈 import와 브라우저 탐색을 모두 지원하도록 설계했다.

## 2. project service 관점

### 서비스라기보다 무엇인가
- 이 저장소는 사용자 서비스보다는 `학습 지식 관리 시스템`에 가깝다.
- 과정 전체를 구조화해 복습, 탐색, 재사용이 가능하도록 만든 내부 도구형 아카이브다.

### 사용자 가치
- 학습자 입장에서 어떤 주차에 어떤 개념과 예제가 있었는지 빠르게 찾을 수 있다.
- 단순 강의 수강이 아니라 `학습 내용을 다시 꺼내 쓸 수 있는 형태`로 전환했다는 점이 가치다.

### 리줌 관점 의미
- 지속적인 학습과 정리 습관
- 구조화된 지식 관리
- 강의 내용을 코드와 설명으로 다시 재구성하는 능력

## 3. 리줌에 쓸 수 있는 포인트
- 5주차 AI 과정을 주차/일차/예제 3계층 학습 아카이브로 구조화
- HTML 대시보드와 Python 모듈 구조를 함께 사용한 학습 자산 관리
- 학습 내용을 복습 가능하고 재사용 가능한 형태로 전환한 경험
