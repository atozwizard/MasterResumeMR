# 사용자_경험_추출

## 목적
`data/user` 전체 자료에서 사용자의 경력과 경험을 마스터 리줌 원재료 기준으로 다시 추출한다.

## 추출 기준
- 기간
- 역할
- 해결한 문제
- 운영 범위
- 성과 또는 정황 근거
- 증빙 수준

## 경력 원재료

### 한솔교육
- 기간: `2011.05 - 2015.09`
- 역할: 영업 및 교육 관리
- 확인 내용:
  - 관리 수업 수를 `50 -> 150`으로 확장
  - `300%` 성장 서사
  - 예비팀장 승진 경험
- 말할 수 있는 문제:
  - 운영 구조와 실행 방식이 성장 속도를 따라가지 못하는 문제
  - 성과를 개인 역량이 아닌 운영 시스템으로 연결해야 하는 문제
- 증빙 수준:
  - 사용자 제공 자기소개서와 포트폴리오 기준 중간 이상

### 브랜드 운영 및 창업
- 기간: `2014.11 - 2025.11`
- 역할: Founder, 운영, 브랜딩, 메뉴/서비스 기획
- 확인 내용:
  - 약 12년간 4회 창업 및 운영
  - 브랜드 운영, 창업, 폐업 경험 포함
  - 상권 분석, 타깃 고객 설정, 메뉴 개발, 운영 최적화 경험
- 말할 수 있는 문제:
  - 상권 한계와 짧은 피크타임 안에서 운영 효율을 확보하는 문제
  - 고객 경험과 재방문을 구조적으로 설계하는 문제
- 증빙 수준:
  - 사용자 문서와 일부 공개 검색 근거 결합, 직접 증빙 추가 필요

### 커피소녀오즈
- 역할: 개인 브랜드 운영
- 확인 내용:
  - 샌드위치와 시그니처 음료 중심의 브랜드 경험 설계
  - B2B 납품 계약 성사 서사
  - 고객 동선과 식사형 카페 포지셔닝 단서
- 말할 수 있는 문제:
  - 고객 페르소나에 맞는 메뉴/공급 전략 설계
  - 장기 거래와 반복 방문 기반 확보
- 증빙 수준:
  - 사용자 문서 + 공개 후기/사업장 흔적

### 우동오즈
- 역할: 자가제면 우동 브랜드 운영
- 확인 내용:
  - 점심 집중형 상권 운영
  - 운영시간과 피크시간 단서 확보
  - 회전율과 조리 병목 문제를 공정 관점에서 다룬 서사
- 말할 수 있는 문제:
  - 짧은 점심 피크타임 안에서 조리 병목을 줄이는 문제
  - 공정 표준화와 회전율 최적화 문제
- 증빙 수준:
  - 사용자 문서 + 운영 정황 근거, 직접 수치 증빙 필요

### 쿤타치 자가제면
- 역할: 자가제면 우동 브랜드 운영
- 확인 내용:
  - 자가제면 공정 데이터화
  - 서빙 시간을 `7분 이내`로 단축했다는 사용자 진술
  - 공간감, 테이블 결제, 시그니처 메뉴 인식 정성 근거
- 말할 수 있는 문제:
  - 긴 조리 시간으로 인한 고객 불만
  - 피크타임 병목과 동선 문제
- 증빙 수준:
  - 사용자 자기소개서 근거 강함, 직접 운영 데이터 필요

### 리틀방콕 중계그린점
- 역할: 프랜차이즈 매장 운영 참여
- 확인 내용:
  - `25평` 규모 매장 HR/CS 관리 서사
  - 프랜차이즈 본사와의 유통/운영 구조 경험
  - 친절, 청결, 양, 재방문 의사 관련 정성 데이터
- 말할 수 있는 문제:
  - 프랜차이즈 운영 표준화와 현장 실행 간극
  - HR/CS 체계 정립과 서비스 완성도 문제
- 증빙 수준:
  - 사용자 문서 + 공개 후기 근거, 직접 증빙 보강 필요

### AI 전환 및 학습
- 기간: `2025.12 - 진행 중`
- 역할: AI 학습자, 프로젝트 구현자
- 확인 내용:
  - SESAC x UPSTAGE 과정 참여
  - 공개 저장소 기반 AI Agent, RAG, FastAPI, 운영형 백엔드 구조 구현
  - 학습 아카이브와 프로젝트 연결
- 말할 수 있는 문제:
  - 현장 문제를 AI와 소프트웨어 구조로 다시 풀어내는 문제
  - 학습을 산출물과 공개 저장소로 연결하는 문제
- 증빙 수준:
  - GitHub 저장소와 포트폴리오 기준 높음

## 경험 해석
- 사용자의 경력은 `영업/교육 성과`, `브랜드 운영`, `프랜차이즈 현장`, `AI 전환` 네 축으로 정리하는 것이 가장 방어력이 높다.
- 브랜드 경력은 정량 수치보다 먼저 `운영 구조`, `고객 경험`, `상권 제약`, `공정 병목` 언어로 정리해두는 편이 적절하다.
